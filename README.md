# TomMart Radio

Мобильное интернет-радио TomMart 24/7.

## Эфир

- музыка из `music/`;
- фирменный джингл TomMart;
- рекламный джингл и рекламные блоки;
- программа «Анекдоты», отдельный джингл и смех;
- общий детерминированный таймлайн: слушатели подключаются к текущему месту эфира, а не начинают плейлист сначала;
- автоматическая ресинхронизация после возврата в браузер или восстановления интернета.

## Обновление медиатеки

При изменениях в `music/` GitHub Actions пересобирает `durations-v15.json` через ffprobe. Радиодвижок использует точные длительности файлов для синхронизации.

Основной движок: `radio-v17.js`.
