# TomMart: ИИ-радиоведущий без платного голоса

## Что добавлено
- GitHub Actions запускается вручную с телефона, без установленного Python и компьютера.
- Неофициальный edge-tts озвучивает русский текст голосами Дмитрий, Светлана и Дарья без отдельного API-ключа.
- Приветствие, пожелания, прощание, шутки и погода работают без ключей.
- Для команды «скажи погоду» данные Open-Meteo берутся по городу из формы запуска. Если их получить не удалось, непроверенная сводка не публикуется.
- При наличии необязательного бесплатного GEMINI_API_KEY нейросеть превращает произвольные указания в естественный радиотекст; без него есть предустановленные фразы и чтение текста.
- Аудиофайл и dj/current.json попадают в основную ветку. После деплоя слушатели получают запись, а музыка временно приглушается.

## Как запустить с телефона
1. Слить PR в main (один раз).
2. Открыть GitHub: YalaCom/radiotommart → Actions → TomMart AI DJ (Russian Edge TTS) → Run workflow.
3. В поле command вписать «Поздоровайся со слушателями, скажи погоду и пожелай хорошего дня».
4. В поле city поставить «Москва» или нужный город. В voice выбрать русский голос.
5. Нажать Run workflow. После успешного выполнения и деплоя Cloudflare Pages реплика попадет к слушателям, уже запустившим радио. Интервал проверки — 8 секунд, плюс время работы GitHub Actions и деплоя.

Другой пример: «Текст: Добрый вечер! Передаем привет слушателям из Казани». Такая команда озвучивается буквально после префикса.

## Для генеративного ИИ
GitHub → репозиторий → Settings → Secrets and variables → Actions → New repository secret → Name: GEMINI_API_KEY, Value: свой API-ключ, полученный в Google AI Studio.
Ключ не нужно публиковать в коде или чате. После добавления ключа Gemini пишет объявления, edge-tts озвучивает. Бесплатные лимиты Gemini зависят от аккаунта и региона. Если Gemini недоступен, используется набор правил.

## Ограничения
- GitHub Models закрыт в июле 2026 года; здесь он не используется.
- Edge TTS — неофициальный интерфейс к онлайн-синтезу Microsoft, его доступность и разрешение на коммерческое использование не гарантированы. Проверяйте условия использования перед коммерческим эфиром.
- Звук формируется в браузерах слушателей, а не на отдельном серверном радиопотоке. Начало объявления у слушателей может различаться из-за задержек сети и браузеров, особенно iPhone и свернутых вкладок. Браузер может блокировать автозапуск второго аудиоэлемента.
- Требуется настроенный автоматический деплой сайта из main на Cloudflare Pages или GitHub Pages.
- Отдельная общедоступная форма команд не добавляется из соображений безопасности; управлять запуском Actions могут пользователи GitHub с правом записи в репозиторий.
